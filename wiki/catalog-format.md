# Каталог сериалов на своём сервере

Приложение берёт список сериалов из одного файла `catalog.json`, который лежит на нашем сервере по HTTPS.
Пример: [`docs/catalog.example.json`](../docs/catalog.example.json).

## Как подключить

1. Положи `catalog.json` на сервер, например рядом с папками видео.
2. В `project.yml` впиши ссылку в `CATALOG_URL` (только `https://`), затем `xcodegen generate`.
   Для проверки без пересборки: в Xcode → Edit Scheme → Run → Arguments добавь
   `-CliffzyCatalogURL https://…/catalog.json`.
3. Пустой `CATALOG_URL` = встроенный демо-каталог.

Приложение кеширует последний удачно загруженный каталог и показывает его без интернета.
Обновил файл на сервере — приложение подхватит его при следующем запуске.

## Формат (version 1)

```json
{
  "version": 1,
  "series": [
    {
      "id": "kontrakt-na-god",          // обязательно, латиницей, не меняется никогда (к нему привязаны покупки)
      "title": "Контракт на год",        // обязательно
      "synopsis": "…",                   // описание
      "genres": ["Романтика"],           // жанры, из них строятся полки, если "shelves" нет
      "poster": "posters/x.jpg",         // 2:3, от 600×900, JPG
      "badge": "New",                    // New | Hot | Exclusive, необязательно
      "views": 0,                        // для «Топа», необязательно
      "regions": ["US", "CA"],           // страны по лицензии (ISO, 2 буквы); нет поля = весь мир
      "episodes": [
        { "number": 1, "title": "Серия 1", "duration": 92, "video": "series/x/ep-0001.mp4" }
      ]
    }
  ],
  "shelves": [                           // необязательно: полки на экране «Обзор»
    { "id": "top", "title": "Топ недели", "style": "ranked", "series": ["kontrakt-na-god"] }
  ]
}
```

- Ссылки в `poster` и `video` могут быть полными (`https://…`) или относительными — тогда они считаются от адреса `catalog.json`.
- `video` — MP4 (H.264/AAC, вертикальное 1080×1920) или HLS-плейлист `.m3u8`.
- Порядок сериалов в файле = порядок в ленте «Для тебя».
- Комментарии `//` выше только для пояснения, в настоящем JSON их быть не должно.

## Видео на Backblaze B2

- Ссылки вида `b2_download_file_by_id?fileId=…` работают, но удобнее «дружелюбные» пути:
  `https://f005.backblazeb2.com/file/<бакет>/<путь>`. Тогда в `catalog.json` можно писать относительные пути.
- Поставь Cloudflare перед бакетом (свой домен, например `media.cliffzy.app`): трафик из B2 в Cloudflare бесплатный,
  а видео кешируется ближе к зрителю.
- Публичный бакет может скачать кто угодно. Для платных серий позже перейдём на подписанные ссылки с коротким сроком жизни.

## MP4 → HLS (быстрый старт видео)

```bash
ffmpeg -i ep-0001.mp4 -c:v libx264 -preset veryfast -crf 21 -c:a aac -b:a 128k \
  -hls_time 4 -hls_playlist_type vod -hls_segment_filename "ep-0001/seg-%03d.ts" ep-0001/index.m3u8
```

## Права и сборка каталога

Каталог не пишется руками, а собирается скриптом из реестра видеоархива и списка прав:

1. В [`content/rights.csv`](../content/rights.csv) одна строка на сериал, который нам разрешено показывать:

   | колонка | что писать |
   | --- | --- |
   | `archive_id` | ID из видеоархива (например `639672`) |
   | `slug` | постоянный ID в приложении латиницей; пусто = из названия. Потом не менять |
   | `title` | название для зрителя |
   | `approved` | `yes` только когда права подтверждены |
   | `rights_holder` | чьи права: Cliffzy или партнёр |
   | `territories` | `WW` = весь мир, или коды стран через запятую: `US, CA` |
   | `valid_until` | дата окончания лицензии `ГГГГ-ММ-ДД`; пусто = бессрочно |
   | `notes` | договор, ссылка и т.п. |

2. Скачай «Реестр .json» со страницы видеоархива и запусти:
   ```bash
   python3 scripts/build_catalog.py --registry registry.json --rights content/rights.csv --out catalog.json
   ```
   Скрипт берёт только одобренные, действующие и полные сериалы, а про остальные пишет, почему пропустил.
   Описания, жанры и постеры можно добавить файлом `--meta content/series-meta.json` (`{"639672": {"title": …, "synopsis": …, "genres": [...], "poster": …}}`).
3. Положи `catalog.json` на сервер. Приложение само скрывает сериалы, у которых в `regions` нет страны зрителя.


### Правило

В каталог попадают только сериалы, на которые у нас есть права: свои AI-сериалы или лицензия, разрешающая
показ в приложении и монетизацию в нужных странах. Чужой контент без лицензии = удаление из App Store и риск
блокировки аккаунта разработчика (App Review Guideline 5.2).
