# 2026-11-25: iOS на общем бэкенде с Android

**Статус:** принято (Андрей попросил пересобрать архитектуру, 2026-11-25). Цены на iOS ждут ответа: только VIP, как на Android, или VIP и монеты.

## Решение

iOS-приложение работает с тем же сервером, что и Android: `cliffzy-api` (репозиторий `cliffzy-backend-android`,
Kotlin + Ktor + PostgreSQL на Render, `https://cliffzy-api.onrender.com`). Каталог в JSON-файле на бакете (PR #3, 2026-11-24) отменён.

| Что | Как |
| --- | --- |
| Вход | Без регистрации: `POST /v1/auth/device` по ID устройства, токен в Keychain. Переустановка сохраняет аккаунт. |
| Каталог | `GET /v1/home` (полки, жанры, весь каталог, «Продолжить»), `GET /v1/series/{id}` (серии, длительности, доступ FREE/VIP/LOCKED). |
| Видео | Закрытый бакет Backblaze B2. Сервер выдаёт ссылку, подписанную на 6 часов (`/episodes/{n}/playback`), закрытую серию без VIP не отдаёт (402). Позже Bunny CDN и HLS, это уже заготовлено в бэкенде. |
| Новые сериалы | GitHub Actions в бэкенде: «Import series from B2» сам читает бакет, считает длительности, делает постер и коммитит `catalog/<id>.json`. Руками ничего не копируется. |
| Оплата | StoreKit 2 → `POST /v1/billing/apple/verify` (подпись Apple проверяется на сервере по корневому сертификату Apple, ключ API не нужен). Продления, окончания и возвраты: App Store Server Notifications V2 на `/v1/billing/apple/notifications`. В покупке передаётся `appAccountToken` = ID аккаунта. VIP один на обе платформы. |
| Мой список, история | На сервере (`/v1/list`, `/v1/history`, `/v1/progress`), лайки на устройстве. |
| Юридическое | Privacy, Terms и «Удалить данные» отдаёт сервер (`/privacy`, `/terms`, `/delete-account`). Удаление аккаунта есть и в приложении (Profile). |

## Почему

- Один сервер на обе платформы: одна база, один VIP, контент добавляется один раз.
- Видео не раздаётся публично: ссылку на закрытую серию нельзя достать из приложения.
- Покупка проверяется на сервере, а не на телефоне: локальный кошелёк App Review не пропустил бы, и его легко подделать.

## Как проверить

- `-CliffzyScreen <экран>`: демо-сервер в памяти (тестовые потоки), для скриншотов CI.
- Обычный запуск: настоящий сервер. CI делает скриншот `live-feed.png` с живым каталогом.
- `-CliffzyAPI <url>`: другой сервер (например, локальный бэкенд).
